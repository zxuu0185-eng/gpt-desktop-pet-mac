# 隐私与数据

## 读取

- CODEX_HOME/sessions、archived_sessions、session_index.jsonl 中的本机可读日志；只覆盖本地数据。
- 可选的辅助功能窗口标题，用于唯一匹配前台 Codex 会话。读不到或有歧义时允许手动固定，不把最近活跃会话当作前台会话。
- 用户选择的角色目录、图片、气泡配图及音频。

## 本机存储

偏好与提醒保存在 `~/Library/Preferences/local.bailong.mac.plist`。导入图片与音频复制到 `~/Library/Application Support/BailongMac/`；目录模式引用原目录，配图引用原路径。统计导出由用户选择保存位置。不会保存原始会话副本。

程序不直接读取或复制账户登录凭据；通过现有本机 Codex 命令连接 app-server 获取额度。Codex 子进程可按自身机制维护状态和连接网络。读取额度不发起模型任务；手动使用 reset 会调用账户权益消费接口。

程序自身不发送截图、会话或图片到外部模型服务，没有遥测或分析SDK。

## 语义限制

上下文余量是日志容量减最近输入的估算；压缩、模型切换与滞后会使估算不可用。Token统计按可读请求记录去重，不是账单。工作状态代表最后记录，不能保证即时同步。已读提醒只属于本应用。

## 卸载

退出后移除app；如需清理偏好和导入资源，再移除上述本应用目录。不要删除 `~/.codex`，它属于Codex。
